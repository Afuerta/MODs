# Afuerta's mods

## Minecraft — Riftbound: Wild Resonance

An original exploration and cooperative combat mod for **Minecraft Java Edition 1.21.1**, using Fabric and Java 21.

Collect four kinds of wild Echoes, build a Rift Anchor, survive increasingly difficult encounters, and turn your Resonance rewards into movement, defense, or mining relics.

Source and instructions: [minecraft/riftbound](minecraft/riftbound/README.md).

- [Claude collaboration handoff](minecraft/riftbound/docs/claude-handoff.md)

Additional mods are kept in separate directories.

## Minecraft — Starfall

A separate mod for **Minecraft Java Edition 1.21.1**, using **NeoForge 21.1.248+** and Java 21.
Chase falling stars, explore glowing craters, forge Starsteel tools, and make wishes.

- [Source and instructions](starfall/README.md)
- [Game design](starfall/DESIGN.md) and [development tasks](starfall/TASKS.md)
