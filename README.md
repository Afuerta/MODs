# Afuerta's mods

## Minecraft — Riftbound: Wild Resonance

An original exploration and cooperative combat mod for **Minecraft Java Edition 1.21.1**, using Fabric and Java 21.

Collect four kinds of wild Echoes, build a Rift Anchor, survive increasingly difficult encounters, and turn your Resonance rewards into movement, defense, or mining relics.

Source and instructions: [minecraft/riftbound](minecraft/riftbound/README.md).
